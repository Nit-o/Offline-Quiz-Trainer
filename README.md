# Offline-Quiz-Trainer
一个HTML渲染器，用于读取Markdown文件并将其转换为测验。

An HTML renderer that reads Markdown files and converts them into a quiz.

## 它能做什么

最开始的目的是用它刷题度过期末。

如果你的老师也给你了题库，同时你也不愿用市面上的各种过于“重”“花哨”的软件，那么这个网页或许会有帮助。
