## 一、正则匹配示例

| 匹配内容示例 | 捕获内容 |
|-------------|----------|
| `## 一、单选题`<br>`## 三、A1型题`<br>`（一）B型题（…）`<br>`二 填空题` | 类型名：`单选题`、`A1型题`、`B型题`、`填空题`（`#` 与小节序数都可省略） |
| `# 第一章、基础医学`<br>`一 选择题` | 章节标题（含序数）；只分节、不改变题型 |
| `### 1. 人体最长的骨骼是？`<br>`1. 人体最长的骨骼是？`<br>`[Q] 心脏位于胸腔的哪个位置？` | 题干文本（不含序号标记；`###` 可省略） |
| `[A] 股骨`<br>`A. 股骨`<br>`A.润 B.漂 C.水飞` | 选项字母与内容；一行写多个选项会自动拆开 |
| `**答案： A**`<br>`**答案：** A`<br>`[T] A`<br>`答案：C`<br>`正确答案：A`<br>`【答案】A` | 答案字符串 `A` / `C` |
| `**解析：** 股骨是人体最长最重的骨骼。`<br>`**答案分析：** …`<br>`答案解析：…`<br>`【解析】…`<br>`解析：…` | 解析文本 |
| `## 四、填空题`<br>`## 五、简答题`<br>`## 六、论述题`<br>`## 七、主观题` | 主观题小节（题型 `subjective`，细分 `fill` / `short` / `essay`） |
| `答案：1.B 2.E` | 共用选项组的合并答案（按题号分回各小题） |

## 二、文本示例

```markdown
# 第一章、基础医学

## 一、单选题/A1型题

### 1. 人体最长的骨骼是？
A. 股骨  
B. 胫骨  
C. 腓骨  
D. 肱骨  
E. 尺骨  
**答案： A**  
**解析：** 股骨是人体最长最重的骨骼。

[Q] 心脏位于胸腔的哪个位置？
[A] 左前方
[B] 右前方
[C] 正中偏左
[D] 正中偏右
[E] 下方
[T] C
**解析：** 心脏约2/3位于正中线左侧。

## 二、多选题/X型题
---

### 2. 以下哪些属于消化腺？
A. 肝  
B. 胰  
C. 脾  
D. 唾液腺  
E. 甲状腺  
**答案： ABD**  
**解析：** 消化腺包括肝、胰和唾液腺，脾和甲状腺不属于消化系统。

## 三、判断题

### 3. 左肺比右肺大。
A. 正确  
B. 错误  
**答案： B**  
**解析：** 右肺宽短，左肺狭长，总体右肺容积更大。

## 四、填空题

### 4. 炮制方法大致可分为___、__、__五类。
**答案：** 修治，水制，火制。

## 五、简答题

### 5. 何谓中药的炮制？
**答案：** 中药的炮制是指药物在应用或制成各种剂型前，根据医疗、调剂、制剂的需要，而进行必要的加工处理的过程。

## 六、论述题

### 6. 中药炮制的目的是什么？
**答案：** ①纯净药材，保证质量；②切制饮片，便于调剂制剂；③干燥药材，利于贮藏。
**解析：** 八个方面详见教材。

```

## 三、主观题（填空 / 简答 / 论述）

小节标题里出现 **填空题 / 简答题 / 论述题 / 主观题** 即按主观题解析（也接受 `## 四、填空题（每空 2 分）` 这类带后缀的写法）：

- **没有选项是常态**：只要有 `**答案：**`（或 `答案：`）就成立，不会因为「缺少选项」被判为错误题。
- **不批改**：题面标注 `(填空)` / `(简答)` / `(论述)`，点「提交答案」（或按 Enter）后才显示参考答案，可再点「收起答案」重新自测一遍。
- **统计口径**：计入答题数，**不计入正确率**（正确率的分母只算客观题，面板会标注「（客观题）」）；错题回顾也不收录主观题。
- **FSRS**：主观题**不自动评分**——提交后出现四档评分条并预选「良好」，按自己的记忆情况选 1-4；评分后不再提供「收起答案」（避免与已评分状态冲突）。
- 主观题小节里若混进带选项的题，会按答案字母数**自动回落**成单选/多选，选项不会被吞掉。
- 参考答案与解析都支持 PDF 转出常见的换行：续行会拼接到上一个字段，中文之间直接相连、不插空格；**客观题的解析必须写在一行内**，换行部分会被丢弃（B/C 型题的合并解析除外，见下）。

## 四、共用选项组（B 型题 / C 型题）

PDF 试卷里 B 型题、C 型题常把一组备选项印在小题**之前**，由随后的几道小题共用，答案写成组末一行。解析器直接支持这种排版，**不需要改题库**：

```markdown
（二）B型题（A、B、C、D、E是下面两道小题的备选项）

A.蜜炙 B.酒炙 C.醋炙
D.姜炙 E.盐炙

1.为了增强药物的活血作用，宜采用：
2.为了增强药物的补肾作用，宜采用：

答案：1.B 2.E

答案分析：酒炙可增强药物的活血之功，故第1题答案应选B；盐炙可引药入肾和增强补肾作用，故第2题答案应选E。
```

- 题号之前的选项行归入「共用选项组」；小题各带一行答案（`答案：B`）也可以。
- 合并答案按题号分发；合并解析按 `第N题` 分回各小题，被版面切断的续行会先拼好再分发。
- 题干会自动加上来源标注 `【B型题·第1小题，备选项共用】`，这样错题回顾、FSRS 单独抽出某一题时信息仍完整。
- 新一组的备选项以 `A` 开头；某道小题漏印答案时会报「缺少答案」，不会静默丢题。

## 五、其他注意事项

题干换行会被拼接，中文之间直接相连（不插空格）：把 `[Q] 心脏位于胸腔` 和下一行 `的哪个位置？` 写成两行，解析结果为 `心脏位于胸腔的哪个位置？`。

其它容易踩的点：

- 一行写多个选项（`A.润 B.漂 C.水飞`）会自动拆开，只在空白后紧跟 `B`–`E` 选项号时切分。
- 选项字母只认 `A`–`E`。
- 小节标题的 `#` 可以省略（`一 选择题`、`（一）A1型题（…）` 都能认）；题号行的 `###` 也可以省略（`1. 题干` 也接受），但这样任何以「数字 + 点」开头的正文行都会被当成新题，务必注意。
- `## 二、多选题/X型题` 里的 `/` 只是给人看的，解析器取第一个匹配到的类型名（这里是「多选题」）；`X型题`、`B型题`、`C型题` 现在都能直接识别（分别是多选、单选、单选）。
