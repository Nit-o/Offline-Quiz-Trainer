## 一、正则匹配示例

| 匹配内容示例 | 捕获内容 |
|-------------|----------|
| `# 第一章、基础医学`<br>`## 一、单选题`<br>`## 三、A1型题` | 类型名：`单选题`、`多选题`、`A1型题` |
| `# 第一章、基础医学`<br>`## 一、单选题` | 章节标题（含序数） |
| `### 1. 人体最长的骨骼是？`<br>`[Q] 心脏位于胸腔的哪个位置？` | 题干文本（不含序号标记） |
| `[A] 股骨`<br>`A. 股骨` | 选项字母 `A`，选项内容 `股骨` |
| `**答案： A**`<br>`[T] A` | 答案字符串 `A` |
| `**解析：** 股骨是人体最长最重的骨骼。` | 解析文本 |

## 二、文本示例

```markdown
# 第一章、基础医学

## 一、单选题/A1型题

### 1. 人体最长的骨骼是？
A. 股骨  
B. 胫骨  
C. 腓骨  
D. 肱骨  
E. 尺骨  
**答案： A**  
**解析：** 股骨是人体最长最重的骨骼。

[Q] 心脏位于胸腔的哪个位置？
[A] 左前方
[B] 右前方
[C] 正中偏左
[D] 正中偏右
[E] 下方
[T] C
**解析：** 心脏约2/3位于正中线左侧。

## 二、多选题/X型题
---

### 2. 以下哪些属于消化腺？
A. 肝  
B. 胰  
C. 脾  
D. 唾液腺  
E. 甲状腺  
**答案： ABD**  
**解析：** 消化腺包括肝、胰和唾液腺，脾和甲状腺不属于消化系统。

## 三、判断题

### 3. 左肺比右肺大。
A. 正确  
B. 错误  
**答案： B**  
**解析：** 右肺宽短，左肺狭长，总体右肺容积更大。

```

## 三、其他注意事项

```
[Q] 心脏位于胸腔
的哪个位置？
```
会解析出`心脏位于胸腔`而不是‘心脏位于胸腔的哪个位置？’需要注意。
